# Inspection Report Comparison

查房报告比对工作台：为 Junior CM 收集证据、CM 审核定损和生成租客报告提供本地工具。

## 快速使用

下载并解压 ZIP，使用现代浏览器打开 `index.html`。无需安装依赖或编译。也可在目录中运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

1. 填写物业地址和两次报告日期。
2. 选择区域，新增问题项目。
3. 拖入本次与之前的照片，填写比对结论及备注。
4. 切换 CM 视角完成审核与对外说明。
5. 下载完整 JSON 备份，或导出租客 HTML 报告并打印为 PDF。

## 功能

- 按区域和审核状态筛选、文字搜索。
- 多图拖拽、压缩、前后大图对照。
- Junior 备注与 CM 对外说明分离。
- IndexedDB 本地自动保存、JSON 备份和恢复。
- 只导出已确认租客责任且证据完整的项目。

## GitHub 使用

建议仓库名：`inspection-report-comparison`。将此文件夹内的文件上传至仓库即可。ZIP 本身是源代码下载包，不代表已创建 GitHub 仓库或发布在线服务。

此分发版本初始为空，未包含真实物业地址、查房记录、照片或客户附件。不要将实际案件备份提交到公开仓库。

## 当前边界

这是单机第一版；角色切换是工作视角，不是账号权限。尚无多人同步、服务端认证、Console 对接或 PDF 自动识别。浏览器清理数据会造成丢失，请定期备份。压缩图片不替代原始证据。

上一份报告未记录问题不能自动推定入住时完好，最终责任须由 CM 结合证据审核。

JavaScript 已通过语法检查；尚未完成真实浏览器交互、打印布局与跨浏览器兼容测试。
